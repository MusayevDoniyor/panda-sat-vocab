## 📌 Overview

**Panda SAT Vocab** is a targeted vocabulary training platform designed for students preparing for the **Digital SAT (Reading & Writing Section)**. It combines cognitive spaced repetition, contextual sentence drills, and high-frequency vocabulary taxonomy to maximize word retention.

## ✨ Core Features

- 🎯 **Digital SAT High-Frequency Taxonomy**: Curated word sets tested frequently on the Digital SAT exam.
- ⚡ **Active Recall Drills**: Interactive flashcards with instant phonetic, definition, and contextual usage tests.
- 📱 **Fast & Mobile-First**: Built with Vite and React for sub-50ms interaction latency on desktop and mobile.
- 🌙 **Modern Cyber-Dark Interface**: High-contrast, distraction-free aesthetic for long study sessions.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript 5
- **Build Tool**: Vite
- **Styling**: Tailwind CSS / Modern CSS
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/MusayevDoniyor/panda-sat-vocab.git

# Install dependencies
npm install

# Start development server
npm run dev
```
